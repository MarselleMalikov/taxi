# Telegram-бот для правки репозитория

Бот правит любые файлы репозитория прямо из Telegram и сразу коммитит в `main`. GitHub Pages обновляет игру примерно за минуту.
Бесплатно: бот работает на Cloudflare Workers (бесплатный тариф: 100 000 запросов в день), правки идут через GitHub API. Компьютер не нужен, всё настраивается в браузере, можно с телефона.

## Что умеет

| Команда | Что делает |
|---|---|
| `/find Гараж` | где в `index.html` встречается текст (номера строк) |
| `/show 450 460` | показать строки с номерами |
| `/replace` + текст (см. ниже) | заменить фрагмент |
| `/line 453 новый текст` | заменить строку целиком |
| `/ins 453` + строки со следующей строки | вставить перед строкой |
| `/del 453 455` | удалить строки |
| `/get` | прислать файл, чтобы поправить его в любом редакторе на телефоне |
| отправить файл документом | заменить им файл в репозитории (в подписи путь, например `tools/sim/bot.js`) |
| `/ls tools` | список файлов |
| `/rm путь` | удалить файл |
| `/log` | последние коммиты |
| `/undo` | откатить последний коммит |

Если путь не указан, бот берёт `index.html`. Чтобы работать с другим файлом, пиши путь первым: `/show dialogues2.js 1 20`.

Замена фрагмента — одним сообщением:
```
/replace
const RENT_COMFORT = 1200
===
const RENT_COMFORT = 1100
```
Старый текст должен встречаться в файле ровно один раз. Если вхождений несколько, бот скажет сколько; для замены всех есть `/replaceall`.
Своё сообщение коммита можно добавить в конце первой строки через ` | `: `/line 5 abc | поправил заголовок`.

## Установка (один раз, ~10 минут)

**1. Бот.** В Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя. Он пришлёт токен вида `123456:ABC...`.

**2. Токен GitHub.** Открой https://github.com/settings/personal-access-tokens/new:
- *Token name*: `taxi-bot`, *Expiration*: сколько хочешь (можно No expiration);
- *Repository access* → **Only select repositories** → `taxi`;
- *Permissions* → *Repository permissions* → **Contents: Read and write**;
- **Generate token** и скопируй его.

**3. Воркер.** Зарегистрируйся на https://dash.cloudflare.com (бесплатно, карта не нужна) → **Workers & Pages** → **Create** → **Start with Hello World** → имя `taxi-bot` → **Deploy**.
Затем **Edit code**: удали всё, вставь содержимое [`worker.js`](worker.js) (на GitHub кнопка *Copy raw file*) → **Deploy**.

**4. Настройки.** В воркере открой **Settings → Variables and Secrets** → **Add**:

| Имя | Тип | Значение |
|---|---|---|
| `TG_TOKEN` | Secret | токен из шага 1 |
| `GH_TOKEN` | Secret | токен из шага 2 |
| `WEBHOOK_SECRET` | Secret | любая длинная строка из латиницы и цифр, например `k3j4h5g6f7d8s9a0` |
| `REPO` | Text | `MarselleMalikov/taxi` |
| `BRANCH` | Text | `main` |
| `ALLOWED_IDS` | Text | пока `0`, исправим в шаге 6 |

**5. Подключение к Telegram.** Открой в браузере (адрес воркера показан на его странице):
```
https://taxi-bot.<твой-поддомен>.workers.dev/setup?secret=<WEBHOOK_SECRET>
```
Должно появиться `"ok": true`.

**6. Доступ только тебе.** Напиши боту что угодно. Он ответит «Нет доступа. Твой id: 123456789». Впиши это число в `ALLOWED_IDS` (шаг 4), сохрани и напиши `/help`. Готово.

## Как обновить бота
Скопируй новый `worker.js` в **Edit code** → **Deploy**. Настройки сохранятся.

## Ограничения и безопасность
- Бот отвечает только людям из `ALLOWED_IDS`. Остальным он сообщает их id и ничего не делает.
- Токены хранятся только в секретах Cloudflare. Никуда их не пересылай. Если токен утёк, отзови его (GitHub → Settings → Developer settings, бот → @BotFather `/revoke`) и выпусти новый.
- Каждая правка — отдельный коммит в `main`, так что любую можно откатить: `/undo` или через историю на GitHub.
- В `index.html` бывают очень длинные строки. `/show` обрезает их до 300 символов, поэтому длинные места удобнее менять через `/replace` по уникальному кусочку.
- Бесплатный тариф Cloudflare даёт мало процессорного времени на запрос. С `index.html` и другими обычными файлами всё работает, а `mapdata.js` и `osmmap.js` (2–4 МБ) могут не пройти. Их лучше не трогать через бота.
