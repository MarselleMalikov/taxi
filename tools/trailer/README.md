# Трейлер игры (вертикальный, 1080x1920, 26,5 с)

Готовый ролик: `promo/trailer.mp4`.

Как пересобрать (нужны node + playwright, ffmpeg, python3 + numpy), запускать из этой папки:

1. `node cap.js` - играет в настоящую игру и снимает клипы покадрово в папки `c_*` (время в игре виртуальное, поэтому кадры ровные). `node trade.js` - переснимает биржу, пока сделка не выйдет в плюс.
2. `python3 music.py` - музыка и звуки, файл `music.wav` (120 ударов в минуту, смена сцен по долям).
3. `node render.js out all` - монтаж `comp.html` (телефон, подписи, переходы) в кадры `out/`.
4. `ffmpeg -framerate 30 -i out/%05d.jpg -i music.wav -c:v libx264 -preset slow -crf 20 -pix_fmt yuv420p -c:a aac -b:a 192k -t 26.5 -movflags +faststart ../../promo/trailer.mp4`

Раскадровка, подписи, касания и «камера» телефона - массивы SC, CAPS, TAPS, CAM в начале скрипта `comp.html` (в кадрах, 30 кадров в секунду).
После пересъёмки клипов сверить кадр конца поездки (метка done клипа C2) с первым кадром в SC и сумму в `#big`.
Имена в рейтинге игроков в ролике выдуманные (сервер рейтинга при съёмке не используется).
